# Как это устроено

*English version: [../ARCHITECTURE.md](../ARCHITECTURE.md)*

Портал — статический сайт без сборки и без зависимостей: HTML + CSS + JavaScript-модули + SVG.
Работает с любого статического хостинга (из любой подпапки) на любом устройстве с браузером.

```
web/
  index.html            сцена (SVG 1000×600), док с кнопками, Лумо, верхняя панель
  style.css             весь визуальный стиль
  src/                  движок (общий для всех приключений)
    app.js              запуск и экраны: старт → небо → приключение → небо; переключатель языка
    scene.js            «язык сцен» — всё, чем пишутся приключения
    sky.js              небо вопросов (главный экран)
    keeper.js           Лумо: SVG-персонаж и его состояния
    voice.js            голос: готовые файлы → синтез браузера → тишина + субтитры
    i18n.js             языки, возрастные версии реплик
    setup.js            первый запуск: язык, возраст, субтитры (один раз)
    settings.js         настройки (шестерёнка): возраст, подсказки, субтитры, микрофон, альбом
    recorder.js         голос ребёнка: запись и хранение (только на устройстве)
    store.js            что ребёнок исследовал + настройки (localStorage)
    sfx.js              звуки, синтезированные на лету (WebAudio)
    space.js            маленький 3D: поворотная камера, проекция, тела от дальних граней к ближним
    svg.js, ui.js       мелкие помощники: геометрия, иконки
  content/              всё, что растёт
    stars.js            карта неба: какие звёзды где и что после чего появляется
    common/             общие реплики (пробуждение, запись голоса)
    sky/                реплики неба + названия и вопросы всех звёзд
    <приключение>/
      script.js         сценарий
      lines.en.js       реплики по-английски (основной язык)
      lines.ru.js       реплики по-русски
  audio/<язык>/         голос Лумо: <хеш>.mp3 + manifest.json (id реплики → файл)
tools/
  serve.mjs             локальный сервер
  lines.mjs             проверка и экспорт реплик
  voice.mjs             озвучка всех реплик (Gemini TTS через OpenRouter)
  dist.mjs              сборка папки для хостинга
  lib/                  общее для инструментов: реплики, клиент OpenRouter
voice.config.json       голос Лумо: модель, голос, манера по языкам
Makefile                make serve | check | voice | dist
```

## Главная идея: движок отдельно, содержание отдельно

**Движок** (`src/`) почти не меняется. **Содержание** (`content/`) растёт без ограничений:
новое приключение — новая папка и одна строка в `stars.js`. Новый язык — новые файлы
`lines.<язык>.js`, сценарии не трогаем.

## Язык сцен

Приключение — асинхронная функция, которая читается как сценарий спектакля:

```js
export default async function (s) {
  const box = s.el('rect', { x: 200, y: 110, width: 600, height: 360, class: 'line' });
  await s.say('look');                       // Лумо говорит (на языке и под возраст ребёнка)
  await s.draw(box, 1100);                   // линия рисуется светом
  const guess = await s.choose([...]);       // кнопки-картинки
  const d = s.drag(handle, { move: (p) => { ... } });   // ребёнок двигает
  await s.until(() => travel > 500, { hints: ['drag.hint1', 'drag.hint2'] });
  s.celebrate(x, y);                         // вспышка Лумо + искры + звон
  s.unlock('pyramid-in-cube');               // повесить новый вопрос на небо
  await s.record('triangle-in-box');         // ребёнок объясняет своим голосом
}
```

* **Подсказки при молчании — каждая один раз.** `until`, `tap`, `choose` принимают `hints`.
  Если ребёнок ничего не делает ~12 секунд (и Лумо молчит), звучит первая подсказка, позже —
  следующая. Каждая подсказка звучит **не больше одного раза за сцену**, дальше Лумо ждёт.
  Взрослые могут выключить подсказки. Тап по Лумо всегда повторяет последнюю фразу.
* **Всё отменяемо.** «Домик» прерывает сценарий в любой точке (`AbortError`), слушатели и
  анимации убираются.
* **Координаты сцены** всегда 1000×600, сцена масштабируется сама.
* **Возраст.** `s.age` — `'small' | 'middle' | 'big'` — для редких случаев, когда должно
  отличаться *поведение* (например, у малышей игра в камешки короче). Слова меняются через реплики.

## Реплики, языки и возраст

* Реплики: `content/<ns>/lines.<язык>.js` — объект `ключ → значение`, где значение:
  * `'текст'` — одинаково для всех;
  * `['а', 'б']` — варианты, Лумо выбирает один;
  * `{ small, middle, big }` — версии под возраст. Нет версии для возраста — берётся `middle`;
    нет и `middle` — реплика просто не звучит (например, `formula: { big: '...' }` — только
    старшие услышат, откуда берётся формула).
* **Основной язык — английский.** `make check` проверяет, что в каждом языке есть все
  реплики английских файлов с теми же возрастными версиями, и что сценарии не ссылаются на
  несуществующие.
* Нет реплики на языке ребёнка — берётся английская, потом русская (с предупреждением).
* **Язык** — как в `nemilya/education`: `?lang=` → последний выбор → язык браузера →
  английский. Переключатель EN / RU — в верхней панели; выбор запоминается и пишется в адрес.
* Новый язык: добавить в `LANGS` в `src/i18n.js`, положить `lines.<язык>.js`, голос в
  `voice.config.json`, затем `make voice`.

## Голос

1. **Готовые файлы** `web/audio/<язык>/<хеш>.mp3`, список — `manifest.json` (id реплики → файл).
   Обычный случай: все реплики на всех языках и для всех возрастов озвучены заранее.
2. **Синтез речи браузера** — запасной вариант для реплик без файла (например, пока пишется
   новое приключение).
3. **Тишина + субтитры** — если голоса нет совсем, субтитры включаются сами.

Id реплик: `ns:key`, варианты `ns:key.1`, возрастные версии `ns:key~big`, `ns:key~big.1`.

```bash
make voice                 # или: node tools/voice.mjs [en ru] [--redo "текст"] [--dry]
```

* Gemini TTS через OpenRouter (`/audio/speech`) — как в `infographics` и `education`;
  голос и описание персонажа — `voice.config.json`.
* Ключ — `OPENROUTER_API_KEY` в окружении или `OPENROUTER_API_KEY = …` в `local.mk` (не в git);
  прокси — `OPENROUTER_PROXY`.
* Имя файла — хеш (модель, голос, манера, текст): синтезируются только новые и изменённые
  реплики, лишние файлы удаляются.
* Каждая новая реплика распознаётся обратно и сверяется с текстом (потерял слова — синтез
  заново, до 3 попыток).
* ffmpeg обрезает тишину, выравнивает громкость, кодирует моно MP3 (~40–60 КБ на реплику).
* Реплики приключения подгружаются заранее при его старте — Лумо отвечает без паузы.

## Голос ребёнка (микрофон)

В конце приключения Лумо предлагает объяснить идею вслух. Запись сразу проигрывается ребёнку
и хранится **только в этом браузере** (IndexedDB) рядом со звездой. Ничего не анализируется и
никуда не отправляется. Обратная связь — живая: взрослые слушают **альбом открытий**
(в настройках) и разговаривают с ребёнком. Если микрофона нет (или страница встроена туда,
где он запрещён), Лумо один раз предлагает рассказать кому-нибудь рядом и больше не
предлагает. Взрослые могут выключить приглашение.

Распознавание объяснения и ответ Лумо по смыслу — в дорожной карте: нужен сервер и явное
согласие родителей.

## Данные и приватность

* Прогресс (зажжённые звёзды, догадки, свои вопросы) и настройки — `localStorage`.
* Голос ребёнка — IndexedDB в этом же браузере. **Никуда не отправляется.**
* Нет аналитики, внешних запросов и аккаунтов.

## Хостинг

```bash
make dist                  # → dist/ и dist.zip
```

Содержимое `dist/` залить в любую подпапку статического хостинга: пути относительные,
сервера и базы не нужно. `.js` — как JavaScript, `.mp3` — как audio/mpeg (по умолчанию так
у nginx и Apache).

## Режимы для разработки

| URL | Что делает |
|---|---|
| `?lang=ru` | принудительно язык |
| `?fast` | без голоса, всё в 8 раз быстрее, субтитры включены — для автотестов |
| `?reset` | забыть прогресс и записи |

## Почему так (а не React / Unity / видео)

* **Нет сборки** — любой автор может открыть файл, поправить реплику и обновить страницу.
* **SVG + код вместо видео** — сцены масштабируются на любой экран, весят килобайты,
  переводятся заменой файла реплик и остаются интерактивными. «Видео» можно делать тем же
  движком: анимированная сцена с голосом Лумо — это мультфильм, сразу на всех языках.
* **ES-модули** работают во всех современных браузерах, в том числе на планшетах.
